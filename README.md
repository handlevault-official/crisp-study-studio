# Crisp Study Studio 📚

A local-first, offline-capable study workshop and productivity assistant built for students and lifelong learners. Part of the **Crisp Suite / HandleVault** ecosystem.

## ✨ Features

- **Pomodoro Focus Timer:** Stay on track with focus sessions, pause/reset controls, and session completion alerts.
- **Interactive Flashcards:** Quick active-recall study flashcards to test your knowledge on key academic concepts.
- **Study Tasks & Checklist:** Manage your assignments, study topics, and daily to-dos with local storage persistence.
- **Night/Day Shift Themes:** Ergonomic high-contrast themes designed for late-night review sessions or bright daytime studying.
- **100% Offline & Private:** Runs entirely client-side in your browser with zero login walls or external server tracking.
- **Single-File Architecture:** Lightweight, fast, and easy to deploy or modify.

---

## 🚀 Quick Start / Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. (Optional) Deploy instantly via GitHub Pages using the included GitHub Actions workflow.

---

## 📂 Repository Structure

- `index.html` — The core single-file application (UI, logic, and styling).
- `repo.js` — Shared Crisp Suite repository metadata helper.
- `manifest.json` — Progressive Web App (PWA) manifest configuration.
- `.github/workflows/deploy.yml` — Automated GitHub Pages deployment pipeline.
